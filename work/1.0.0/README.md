# 1.0.0 — A trustworthy GitOdile

The release epic [065](065-release-1.0.md) owns the `1.0.0` acceptance
criteria. Its children are delivered by
[`0.5.0`](../0.5.0/README.md), [`0.6.0`](../0.6.0/README.md) and
[`0.7.0`](../0.7.0/README.md); this folder holds no queued task of its own.

## Goal

The ordinary, provider-neutral Git lifecycle at the level of GitHub Desktop,
complete and safe without a terminal, shipped as verified installable
artifacts. It is the foundation for the post-`1.0.0` direction in the
[roadmap](../../docs/ROADMAP.md#after-100); no feature of that direction is
added before `1.0.0` ships.

## Exit condition

Every acceptance criterion of epic 065 is met on the actual artifacts.
