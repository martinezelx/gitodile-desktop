# GitOdile 0.3.0-preview.1

<!-- gitodile-highlights:start -->
## Highlights

- Overview walks you through Changes, Save and Publish and points out the next step, and Changes and History are now the two tabs of one Work screen.
- Lines shows where each version line left the main line, what it changes and whether its work is already there, even as copies.
- The new Console runs read-only Git queries, such as status, log or branches, by short names you can change.
- GitOdile has a new mascot and icon, and Settings offers colour themes: Catppuccin, Nord, Tokyo Night, Dracula, Solarized and Gruvbox beside its own light and dark.
- Choose between stable and preview updates in Settings → Updates, and the update dialog lists what a new version brings, in your language.
<!-- gitodile-highlights:end -->

This first testing preview of 0.3 reorganises the everyday workflow around
three steps, rebuilds the version lines screen, adds a read-only Git console
and gives GitOdile a new look. It is intended as the target of a
preview-to-preview update test from 0.2.0-preview.12.

- Overview is rebuilt as one page: a band of three steps, Changes, Save and
  Publish, highlights the next thing to do, and Recent history marks the
  saved versions that are not published yet, with publishing one click away.
- Changes and History are now the two tabs of a single Work screen, sharing
  one layout, one diff toolbar and one find. Saving happens from one box under
  the file list, which states the plan before you save, and both file lists
  can be read as folders.
- When there is nothing to save, the Changes tab explains where the project
  stands (unpublished versions, newer changes on the remote, no saved versions
  yet, or an old version checked out) and offers the one action that fits.
- History shows each saved version as a single view: its message and details
  fold away, and the changes are always visible. Rows mark your own versions,
  tags and the ones not published yet, and a filter shows only tagged
  versions.
- Lines is rebuilt around the same shape. The selected line shows where it
  left the main line, the versions each side saved since, what it changes,
  and whether its work already reached the main line, including as squashed
  or rebased copies. Lines are created and renamed in place, with their names
  checked before you press. Deleting a line whose work is only on the main
  line as copies keeps a recovery point for its original versions first.
- A new Console screen runs a fixed set of read-only Git queries (status,
  diff, log, graph, branches, tags, remotes and more) by short names you can
  edit. It cannot change the project.
- The Projects screen stays reachable from More actions and the command
  palette while projects are open, to open another one, and the
  keyboard-shortcuts sheet groups every shortcut and draws the keys as your
  platform names them.
- Save and Publish open at once in their final shape and confirm their plan
  while you read it, and first loads draw the layout they are about to fill.
- Every action dialog shares one layout, and finished results such as a
  publish or getting project changes close with a short notice instead of
  another dialog.
- The status bar shows how many lines changed in your working files, and its
  cloud opens publishing while there is something to send.
- Notifications are an inbox: an unread dot replaces the red counter, and
  entries can be dismissed one by one.
- Settings offers colour themes: GitOdile's own light and dark, plus
  Catppuccin (Mocha, Latte and Frappé), Nord, Tokyo Night, Dracula, Solarized
  (Dark and Light) and Gruvbox (Dark and Light). Every theme keeps text,
  buttons, the diff and its syntax colours readable, measured against the
  WCAG AA contrast floors.
- Settings → Updates lets you choose between stable and preview updates.
  Switching asks for confirmation and checks the chosen channel straight away;
  the installed version stays, because GitOdile never downgrades.
- The update feed now carries each release's highlights in English and
  Spanish. Builds from this one on show them in the update dialog, in your
  language, when a newer version is offered; 0.2.0-preview.12 still shows the
  plain notes when it offers this update.
- Preview builds are marked with a small flask next to the version instead of
  a repeated "preview" label. About leads with the app's identity and says
  whether the build is up to date.
- GitOdile has a new mascot, a crocodile in sunglasses, as its icon and on the
  welcome and About screens. The Windows installer carries the icon
  and artwork, is available in English and Spanish, and keeps desktop and
  Start-menu shortcut icons intact across updates.
- Windows is provided as an NSIS installer. Authenticode remains deliberately
  deferred, so Windows may show an unknown-publisher or SmartScreen warning.
- Linux is provided as an AppImage.
- Both packages verify updates with the production Tauri updater key and the
  public `preview.json` feed in `martinezelx/gitodile`.
- macOS remains disabled and no macOS package is included.

Publishing this preview does not declare either target qualified and does not
authorize stable publication.
