# GitOdile 0.3.1

<!-- gitodile-highlights:start -->
## Highlights

- Overview now tells you before you press anything whether getting project changes overlaps your work; when nothing overlaps, one confirmation gets them, combines them with your unpublished versions and can publish too.
- When a line's branch is deleted on the remote, usually after its pull request is merged, GitOdile says so, offers to switch to the main line, and asks before publishing would create it again.
- GitOdile has a new look: a simpler, flat crocodile in the app, and a new app icon: the whole crocodile on white, clear even at small sizes.
