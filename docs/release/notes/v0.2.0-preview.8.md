# GitOdile 0.2.0-preview.8

This testing preview delivers the current GitOdile desktop application as
downloadable Windows x86-64 and Linux x86-64 packages.

- Windows is provided as an NSIS installer. Authenticode is intentionally
  deferred, so Windows may show an unknown-publisher or SmartScreen warning.
- Linux is provided as an AppImage for manual installation and testing.
- Both packages carry the production Tauri updater signature and are bound to
  the exact merged source commit.
- macOS remains disabled and no macOS package is included.

This prerelease validates the protected build and publication pipeline. It does
not claim that Windows or Linux installed updates are qualified yet.
