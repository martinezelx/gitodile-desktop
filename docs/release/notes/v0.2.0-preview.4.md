# GitOdile 0.2.0-preview.4

First corrected validation-key preview in the Windows x86-64 NSIS and Linux
x86-64 AppImage qualification sequence. It removes the duplicate manifest
preflight exposed by the immutable `.2`/`.3` attempt: Tauri's updater client is
now the only feed authority, and GitOdile strictly validates its returned JSON.
macOS packages are not published in this phase.

This preview establishes the installed starting point for the controlled
0.2.0-preview.4 to 0.2.0-preview.5 update test.
