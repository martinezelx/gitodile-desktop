# GitOdile 0.2.0-preview.12

This testing preview hardens the updater after the first public previews
updated real installations. It is intended as the target of a
preview-to-preview update test from 0.2.0-preview.11, and it is the first
preview whose update information carries the real publication time and
readable release notes.

- A build that cannot install updates by itself says so as soon as it checks,
  in plain words, and offers the manual download instead of downloading a
  package and refusing it afterwards.
- Installed clients no longer depend on the update feed listing only the
  platforms they know. Enabling macOS in the feed later will not stop Windows
  and Linux installations from updating.
- On Windows, a per-user installation in a custom directory is recognised
  and can update in place; a machine-wide installation is still directed to
  the installer.
- Release notes in the update dialog keep their paragraphs and bullets, and
  the shown publication date is the moment the release was actually
  published.
- Windows is provided as an NSIS installer. Authenticode remains deliberately
  deferred, so Windows may show an unknown-publisher or SmartScreen warning.
- Linux is provided as an AppImage.
- Both packages verify updates with the production Tauri updater key and the
  public `preview.json` feed in `martinezelx/gitodile`.
- macOS remains disabled and no macOS package is included.

Publishing this preview does not declare either target qualified and does not
authorize stable publication.
