# GitOdile 0.2.0-preview.1

First version prepared under the two-channel (stable/preview) release policy,
on 2026-09-03. It was the development version on `main` while the signed
updater was being designed; no tag, package or public release was produced,
and it was superseded by 0.2.0-preview.2 on 2026-09-12. This file records the
version for completeness only.

- Report an issue from More actions. Review the app and system details before
  submitting your report on GitHub.
- Preview builds now show their full version number so you can identify the
  build you are using.
- Open these release notes from the version tag in the status bar, or from
  the toolbar menu.
- GitOdile now uses its canonical name and application identity consistently.
