# GitOdile 0.1.0

First tagged GitOdile release, dated 2026-08-27, before the application
updater and the automated release pipeline existed. It was not distributed as
a signed package and cannot receive in-app updates; installing any later
version is a manual reinstall.

- Open, clone, or create local projects, and pick your last session up where
  you left it.
- Save all or selected changes as a version, then publish it through a
  previewed flow that reports uncertain remote outcomes honestly.
- Browse the saved-version timeline and read syntax-colored diffs for any
  change.
- See your current version line, unsaved work, and when project changes were
  last checked from every screen.
- Switch version lines from the status bar with the same preview and
  unsaved-work safeguards.
