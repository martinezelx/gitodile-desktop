# Contribution policy

GitOdile is developed and maintained by its author. External code contributions
and pull requests are not currently accepted.

## Report a bug

Bug reports are welcome in the
[public issue tracker](https://github.com/martinezelx/gitodile/issues).
Search existing issues before opening a new report.

Use **More actions → Report an issue** in GitOdile to prepare a report you can
review before submitting. Include:

- your GitOdile version and operating system;
- the steps needed to reproduce the problem;
- what you expected and what actually happened;
- a screenshot, if useful, with private information removed.

Never include access tokens, passwords, or private source code in a public issue.

## Report a security vulnerability

Use the
[private security reporting channel](https://github.com/martinezelx/gitodile/security/advisories/new)
instead of a public issue. See [SECURITY.md](SECURITY.md) for the security policy.

## Maintainer documentation

The [README](README.md#development) covers local setup and build commands.
[AGENTS.md](AGENTS.md) owns engineering, release, safety, and validation rules.
These instructions support maintainer work and building from source; they are
not an invitation to submit external changes.
